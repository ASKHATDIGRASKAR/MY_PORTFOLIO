🛠 How to Edit This Code

You can update and manage this portfolio project in several ways:

Option 1: Edit via Online Dashboard

If your project is hosted on a web-based dashboard or deployment platform (like Vercel or Netlify), you can edit your files locally or directly through their online editor — changes will automatically reflect after deployment.

Option 2: Use Your Preferred IDE (Recommended)

Work locally for full control and customization.

Make sure you have Node.js and npm installed — install using nvm
.

Then follow these steps:

# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project folder
cd akshat-portfolio

# Step 3: Install dependencies
npm install

# Step 4: Run the development server
npm run dev


Now open your browser and visit http://localhost:5173 (or the port shown in your terminal) to preview your portfolio live.

Option 3: Edit Directly on GitHub

Go to your GitHub repository.

Open the file you want to modify.

Click the ✏️ (Edit) icon.

Make your changes and commit them directly.

Option 4: Use GitHub Codespaces

Go to your repository’s main page.

Click the green Code button → Codespaces tab.

Launch a new Codespace to get a full development environment in your browser.

Edit, preview, and push changes instantly.

🌍 Deployment

Deployed using Vercel, ensuring fast performance and global availability.
To redeploy, simply push your latest changes to the main branch — Vercel will automatically build and deploy your updated site.

🔗 Custom Domain Setup

To connect your custom domain (like akshatdigraskar.vercel.app or akshatdigraskar.dev):

Open your Vercel Dashboard → Domains

Click Add Domain

Enter your domain name and update your DNS records as instructed

Once verified, your portfolio will be live on your domain

For more help, check Vercel’s Custom Domain Setup Guide
.
